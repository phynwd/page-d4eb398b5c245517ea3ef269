使用场景

网络加速不是把所有流量都塞进同一条通道。快柠檬更适合把「需要稳定跨境访问」的那一部分单独交给订阅节点，本机日常浏览仍可走原网络。

  • 查阅与协作文档、邮件、会议链接或海外知识库打不开、反复跳转时，用客户端接入后再打开对应应用，比整机全局代理更可控。
  • 流媒体与内容站点页面能开、片源却区域限制时，先确认客户端规则是否覆盖该域名，再决定是否切换节点。具体解锁范围以套餐说明为准。
  • 学习与开发拉取仓库、读文档、访问学术或云控制台时，延迟和握手失败会打断节奏。保持客户端常驻、按需开启，比反复重装更省事。
  • 出行与公共网络酒店或咖啡馆的公共 Wi-Fi 上，用自己的订阅通道访问敏感页面，减少直接暴露原网络请求。
  • 游戏与实时应用若你的套餐包含游戏向线路，请在对应客户端里单独分流游戏进程，避免把下载盘满整条通道。未在套餐中写明的能力，本页不作承诺。

操作说明

流程刻意写短：先客户端，后订阅，再连接。快柠檬不要求你理解底层协议，但需要你按顺序完成下面几步。

  1. 在本页客户端区域选择与系统匹配的程序并完成安装。只保留一个主力客户端，避免多个代理程序抢路由。
  2. 到订阅区域确认适合自己的方案。套餐数字、流量与设备上限以模块原文为准，不要凭记忆改写。
  3. 将机场订阅导入客户端。优先使用订阅链接自动更新，而不是一次性手动节点列表。
  4. 先做一次连通测试：打开一个你平时打不开的页面或应用。成功后再把常用域名写入分流规则。
  5. 日常使用时按场景开关。不需要加速的本地银行、政务与视频缓存，尽量走直连，减少无意义消耗。

导入失败时先核对

检查订阅是否过期、客户端是否过旧、系统时间是否准确，以及是否把 HTTP 订阅贴进了只接受其他格式的输入框。这三项能覆盖大部分「显示已导入却没有任何节点」的情况。

常见问题

快柠檬是什么？和普通 VPN 有何不同？

快柠檬以机场订阅为核心：你在官网确认方案后，把订阅导入自己选择的客户端，由客户端负责连接与分流。它和「安装一个封闭 App 就结束」的单一 VPN 产品不同，重点在订阅与客户端的组合，而不是一个打包死的入口。

为什么把客户端选择放在最前面？

同一条订阅，在不同客户端里的规则语法、TUN 模式和系统代理接管方式并不一样。先选定客户端，可以避免导入后看起来「有节点」却无法真正接管流量。本页 accordingly 把客户端模块前置，方便对照系统再往下看订阅。

没有技术基础，能不能独立完成配置？

可以。按「安装客户端 → 复制订阅 → 在客户端点更新 → 开启连接」即可。不需要手写规则。若更新后列表为空，回到订阅模块确认方案仍有效，再检查是否粘贴了完整链接。

可以同时在多台设备上使用吗？

可以，但同时在线的数量受你所选方案限制。请以订阅模块中的设备说明为准，不要在正文或口头传播里改写数字。超出上限时，通常是新设备挤掉旧会话，表现为随机掉线。

快柠檬官网提供安装包下载吗？

客户端下载以本页客户端模块中的链接为准。本页不另列第三方网盘、不编造官方包地址。若模块暂未出现某一系统，请等待入口更新，不要改用来路不明的同名软件。

流量用在什么地方最合适？

优先留给需要跨境访问的查阅、协作、流媒体和开发拉取。系统更新、大文件网盘、长时间挂机直播会迅速耗尽月流量。客户端里把这些域名设为直连，通常比频繁升级套餐更有效。

连接成功但个别网站仍打不开，怎么办？

先区分是 DNS 污染、规则未覆盖，还是目标站本身限制数据中心 IP。可尝试：更新订阅、更换同一套餐内的其他节点、把该域名加入代理列表。若仅某个 App 失败，检查是否开启了该 App 的分应用代理。
